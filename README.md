Лабораторная работа №5
1. normalized.py 
Что делает: убирает лишние пробельные символы (схлопывает в один пробел), выводит исходную и новую длину, нормализованный текст и количество слов.
Проверки:
text.split() без аргумента разбивает по любым пробельным символам и отбрасывает пустые фрагменты — так удаляются ведущие, хвостовые и множественные пробелы.
Условие if normalized else [] корректно обрабатывает пустую строку: если после нормализации ничего не осталось, words становится пустым списком, и len(words) даёт 0.
Результаты:
Для " Hello world ": исходная длина 16, новая длина 11, текст "hello world"? — нет, регистр не меняется: "Hello world", количество слов 2.
2. palindrome.py 
Что делает: убирает пробелы, приводит символы к нижнему регистру, затем сравнивает строку с её перевёрнутой версией (c[::-1]).
Проверки:
Пропуск пробелов (if i != ' ') — пробелы не учитываются при проверке.
Приведение к нижнему регистру (lower) — регистр не влияет на результат.
Пустая строка обрабатывается отдельно: выводится 'Слов нет' (проверка if a=="").
Результаты:
"А роза упала на лапу Азора" → c = "арозаупаланалапуазора", совпадает с перевёрнутой → Палиндром.
"привет" → Не палиндром.
3. replace.py 
Проверки:
count(':') считает все вхождения подстроки.
replace(':', '-') заменяет все вхождения (без ограничения количества).
Пустая строка обрабатывается естественно: c = 0, строка остаётся пустой.
Результаты:
"a:b:c" → 2 a-b-c.
"нет двоеточий" → 0 нет двоеточий.
Пустая строка → 0 и пустая строка.
4. variant.py
Проверки:
split() — разбиение по пробельным символам.
strip(".,!?;:") — удаление указанных знаков пунктуации с обоих концов слова.
lower() — сравнение без учёта регистра.
Условие i[0] == i[-1] — первая и последняя буквы совпадают.
Результаты:

"Анна. кот, топот!" → слова после обработки: анна, кот, топот. Совпадают края у анна (а—а) и топот (т—т) → печатается анна, топот. (кот: к≠т — не печатается.)
